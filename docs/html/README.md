# Saved HTML notebooks

[Browse saved outputs](https://demotu.github.io/detecta/docs/html/).
These pages contain saved text and plots, with links to the corresponding
editable notebook and alternative execution services. Reading does not execute
Python; display assets still need an Internet connection.

Sources remain in [docs/](../). Refresh changed snapshots with
`uv run --group docs python scripts/export_notebooks.py` and commit the affected
source, HTML and manifest together. See [scripts/README.md](../../scripts/README.md).
